# Asset provenance and publication

## Thunder Mountain photograph

`public/images/thunder-mountain-reference.webp` is a compressed WebP conversion of the first sunset photograph supplied by Daniel in this conversation, originally a 1628 x 724 screenshot. The photograph depicts the landscape the user identified as Thunder Mountain. It was not regenerated or replaced with an invented Sedona mountain. Its full image framing and visible photographer signature remain in the asset; responsive layout crops may display different portions.

The screenshot is a reference image, not proof of ownership or permission. The photographer's identity, required credit wording and publication license have **not** been verified. Obtain an authorized original and permission covering website use, or replace the image with a photograph you own. Confirm requirements before making the repository or site public. Do not remove the signature merely to make the design cleaner.

To replace: save an authorized image at the same path, or change the reference in `app/page.tsx` and the CSS background declaration in `app/globals.css`. Keep the recognizable actual Thunder Mountain silhouette. A landscape original of roughly 2000+ pixels wide will give more latitude than the screenshot. Update this file with the actual source, license/permission and required credit.

## Logo and game artwork

The small Sedona wordmark/ridge and the dice/tile/card/pawn illustrations are prototype SVG/CSS artwork created for this site. Commercial game packaging images have not been downloaded or copied. Game names identify the games available and do not imply publisher sponsorship. Confirm actual availability before an event.

## Fonts

The source refers to Fraunces and Inter via npm Fontsource dependencies. Font binaries are **not** included in this delivery. Install the dependencies normally; observe their bundled licenses. The standalone preview uses available local fallback fonts and may differ slightly from the deployed webfonts.
